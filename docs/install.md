# Install

Use .NET SDK 10.0.401 and Aspire CLI 13.6.5. Add `PinguApps.Aspire.Hosting.Railway` version 1.0.0 to the AppHost.

```json
{ "sdk": { "version": "13.6.5" }, "packages": { "PinguApps.Aspire.Hosting.Railway": "1.0.0" } }
```

A pre-created project/environment, recorded allocation, matching shared `PINGUAPPS_SITE_KEY`, and scoped project token are required. Initial allocation stays separate from routine deployment.
