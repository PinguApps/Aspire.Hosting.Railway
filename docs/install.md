# Install

Use .NET 10 and Aspire CLI 17.0.0 or later. The integration requires Aspire 17.0.0 or later. Add `PinguApps.Aspire.Hosting.Railway` to the AppHost.

```json
{ "sdk": { "version": "17.0.0" }, "packages": { "PinguApps.Aspire.Hosting.Railway": "1.1.6" } }
```

A pre-created project/environment, recorded allocation, matching shared `PINGUAPPS_SITE_KEY`, and scoped project token are required. Initial allocation stays separate from routine deployment.
